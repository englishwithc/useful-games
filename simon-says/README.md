## 🎮 How to Play: The Basics

The game runs automatically on a loop. Here is how the standard mode works:

1. **Look & Listen:** The screen displays a large emoji and text (e.g., *"Simon Says JUMP"*).
2. **Action:** You read the text aloud or let the computer speak it. Students perform the action shown.
3. **The Twist:** If the screen shows an action *without* saying "Simon Says," students must **FREEZE** and do nothing. If they move, they are out!

|--------|-------|----------|
| 🐢 Slow | 🐢 | Younger kids or beginners who need more time to process |
| 🚶 Normal | 🚶 | The standard pace |
| ⚡ Fast | ⚡ | Older students or a high-energy warm-up |

### 🎭 Trap Mode (The "Fake Out")

This mode adds a surprise element. Most turns work normally, but occasionally the game will show an action **without** the "Simon Says" header.

**How it works:**
1. The screen shows an action (e.g., *Clap*).
2. Students see the action and might start to clap.
3. Suddenly, the screen flashes red and says **"FREEZE!"**
4. Anyone who moved before the flash is caught!

### 🔁 Repetition Mode

Instead of doing an action once, students must do it multiple times.

- The game picks a random number between 1 and 10.
- If it says **"Simon Says Clap (5)"**, students will see the number on screen and count out loud as they clap 5 times.
- **Note:** The game automatically waits longer for higher numbers so students have time to finish!

## 💡 Teacher Tips & Best Practices

| Tip | Description |
|-----|-------------|
| 📋 Before You Start | Always check your vocabulary list. If teaching body parts, uncheck "Jump" and only leave "Touch your nose," "Touch your ears," etc. |
| 🎯 Using Trap Mode | Great for listening skills. Remind students that if the text doesn't start with "Simon Says," they should wait for the "Freeze" signal before moving. |
| ⚡ Energy Management | Use the Speed Selector to ramp up energy. Start in "Slow" mode to warm up, then switch to "Fast" mode when the class is ready. |
| 🛑 The Stop Button | If you need to pause the game or change settings, click the big red **STOP** button. It will return you to the main menu immediately. |
