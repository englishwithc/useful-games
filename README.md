# 🌟 English with C - Useful Games Hub

A collection of interactive ESL tools and games designed for classroom use — all hosted on GitHub Pages for easy access during lessons.

## 📁 What Is This?

This is a central navigation hub that links to all the individual game folders in this repository. Each game lives in its own folder, but this page brings them together into one organized collection that teachers can quickly navigate.

## 🚀 How to Use It

1. **Navigate to this repo** on GitHub:  
   https://englishwithc.github.io/useful-games/

2. **Use the filter buttons** at the top to jump between categories like Board Games, Vocabulary, Typing, Scoring Systems, and Listening games.

3. **Click any game card** to see its description and a "Play Game" button that opens the game in a new tab.

## 🎨 Features

- ✅ Color-coded category bands on each card
- ✅ Emoji icons to quickly identify game purpose
- ✅ Expandable cards showing descriptions & teacher tips
- ✅ Filter buttons to sort by topic
- ✅ Responsive design (works on tablets and phones)
- ✅ No JavaScript files or external dependencies — everything is in one HTML file
